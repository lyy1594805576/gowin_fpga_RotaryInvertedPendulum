# 验证范围

`sim/run_tests.py` 从 Gowin 工程的启用文件列表编译 `top`（Verilog-2001），然后执行 `sim/cases.json` 中的八个独立模块测试：定点 PID、电机 PWM、ADC 相位/抗毛刺/平均、二进制转十进制、调试 UART 和100Hz遥测 UART。

`--host-tests` 还运行日志自检、PID事务/虚拟串口/Tk界面、摩擦前馈界面，以及位置上位机协议与隐藏窗口测试。运行器向 Icarus 显式提供标准输入管道，避免部分 Windows Icarus 发行版遇到 NUL 标准输入时崩溃。

这是一组可从独立克隆运行的基础检查。原目录部分历史回归需要未开源的旧备份、兄弟目录或外部仿真器绝对路径，没有混入此入口；当前控制逻辑的完整覆盖和真实机械闭环性能需要单独验证。

GitHub Actions运行相同入口，使用虚拟显示器运行Tk测试。FPGA厂商工具未打包，CI不进行Gowin综合、布局布线或硬件烧录。时序结论必须来自使用者自己的新鲜构建和 `verify_build.py`。
